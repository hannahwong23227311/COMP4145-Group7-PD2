## Project purpose
SmartInvestor AI is a Streamlit-based investment-learning prototype designed for non-professional investors. The platform enables market exploration, stock comparison, portfolio analysis, a simple moving-average strategy backtest, and optional AI-powered explanations. It is intended for learning and decision support only; it does not execute trades or provide personalised financial advice.

## Initial project update
The repository already contained a working multipage Streamlit app, historical stock data, and supporting modules before this round of updates. The current implementation includes a dashboard, stock analysis, comparison, portfolio, AI advisor, and strategy backtest. The project was extended from this baseline to improve usability, reliability, and documentation.

## Selected enhancements
- Portfolio analytics: editable holdings, quantity, and cost inputs; calculation of market value, cost basis, unrealised gain/loss, and allocation.
- Strategy backtest: simple moving-average crossover using the included dataset, with comparison against buy-and-hold behaviour and drawdown reporting.
- AI advisor: HKBU GenAI endpoint integration using a bearer token, request validation, and user-facing API error handling.
- Documentation and reliability: clearer installation instructions, dataset limitations, and validation for missing-data and comparison edge cases.
